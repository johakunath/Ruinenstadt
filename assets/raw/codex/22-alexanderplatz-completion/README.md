# Alexanderplatz environment completion

Sources: original image-tool paintings, not traced from the old renderers.
Style source: docs/style/alexanderplatz-pioneer.png and docs/style-bible.md.

- style-canvas.png establishes architecture, ink, daylight and Pioneer palette.
- material-atlas.png: 4 × 3 flat facade/material modules; twelve 256px cuts.
- landmark-sheet.png: three alpha-separated upright sprites; natural silhouettes.
- game-size.png: all selected assets at 64px.
- cuts.json: exact source crop and output dimensions.

Run `python3 tools/build_alex_completion.py` to reproduce the fifteen WebPs.
The old architecture supplies only projection/footprint, not the painted designs.
Existing GDR block art, banners, enemies and gameplay are retained.
