# Three final district boards · 2026-11-13

Johannes selected Tempelhof B, Wedding C and Charlottenburg A+C from the nine
exploration boards and requested these detailed final refinements. The parent
folder preserves the exploration originals. `prompts.json` records the exact
new prompts and source reference images. `generations.json` maps original
tool output files to the preserved raw PNGs and canonical style references.

| Raw original | Canonical reference | Direction |
|---|---|---|
| `tempelhof-final.png` | `docs/style/tempelhof.png` | 1948 wind/airplane cult, frightening magic and elaborate sailcloth robes |
| `wedding-final.png` | `docs/style/wedding.png` | “kommt bald”, lavish enchanted banquet, gold/emerald, carpets, lamps, food and tea |
| `charlottenburg-final.png` | `docs/style/charlottenburg.png` | 1920 revue, silver/diamonds/glass, elaborate stage costumes and mirror palace |

Each board contains a key scene, three building studies, at least three
ordinary enemy types plus a separate legendary boss, a complete emblematic set
in front/back views and one legendary weapon with details. All omit BVG
branding, transit livery and transit-worker costume motifs. Wedding's living
neighbours are hosts/allies; enchanted feast beings are the comic adversaries.

The canonical files are byte-identical copies, not additional generations.
The files in `/workspace/generated_images/` are preserved. No runtime sprites,
manifest entries, game code, cache/version changes or game performance claim.
The single final-batch file-validation pass is recorded in `validation.json`.
