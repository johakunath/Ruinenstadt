using `docs/style/koepenick.png` as the visual reference, with district lore
from `docs/story.md`. `prompts.json` records every exact prompt and reference.

These are **proposals, pending Johannes's selection/mixing**, not sprites or
approved production designs. Read the comparison and view all nine boards in
[`docs/district-design-directions.md`](../../../../docs/district-design-directions.md).
The original files in `/workspace/generated_images/` are preserved too.

No runtime manifest, loader, service-worker shell, gameplay, version or cache
changes. `validation.json` records the single file-validation pass, encoded
sizes and conservative RGBA decoded sizes. Board-viewing memory is separate
from game texture memory, which this batch increases by zero. No game timing
or hardware performance pass is claimed.
